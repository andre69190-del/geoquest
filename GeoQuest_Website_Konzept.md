### SEKTION 4 -- Spieltypen erklaert (Wie funktioniert GeoQuest?)

**Ueberschrift:** "5 Spielprinzipien. Unendlich viele Variationen."

**5 Feature-Cards mit Icons, Titel, 2-Satz-Erklaerung + Screenshot-Placeholder:**

1. **📍 Karte-Pin**
   Siehst du einen Begriff -- du pinnst seinen Ursprungsort auf die Weltkarte.
   Je naeher dein Pin, desto mehr Punkte. *Beispiel: "Camp Nou" -- pinne Barcelona.*

2. **📊 Hoeher / Niedriger**
   Zwei Entitaeten werden verglichen -- du entscheidest, welche den groesseren Wert hat.
   Schlauer Algorithmus waehlt nur aehnliche Paare (kein Ameise vs. Elefant).

3. **🎯 Zuordnen (Match)**
   Multiple Choice -- ordne Begriff seinem Land/Kontinent/Kategorie zu.
   Distraktoren kommen aus thematisch verwandten Kategorien.

4. **🔤 Wort-Schmiede**
   Aus den Buchstaben eines Fachbegriffs Woerter bilden -- wie Scrabble.
   Zweisprachig: Deutsch & Englisch.

5. **🌐 Klassisch**
   Flagge erkennen, Hauptstadt nennen, Land aus Umriss raten --
   das bewaehrte Geografie-Grundprinzip in vielen Variationen.

### SEKTION 6 -- Download / Installation

**Ueberschrift:** "Spielen. Sofort. Ueberall."

**3 Optionen nebeneinander:**

#### Option A: Direkt spielen (empfohlen)
- Kein Download, kein Install
- Oeffnet direkt im Browser
- `[Jetzt spielen -->]` (grosser gruener Button)
- Hinweis: *Funktioniert auf Desktop, Tablet & Handy*

#### Option B: Als PWA installieren
- Auf Handy/Desktop installieren wie eine App
- Erscheint im Homescreen / Startmenue
- Offline spielbar nach erstem Laden
- **Anleitung:**
  1. App im Browser oeffnen
  2. Browser-Menue > "Zum Startbildschirm"
  3. Fertig -- Icon erscheint wie jede andere App
- `[App oeffnen & installieren]`

#### Option C: Datei herunterladen
- Fuer Offline-Archivierung, Schulen, Netzwerke ohne Internet
- Eine einzige HTML-Datei (2.4 MB)
- Ueberall per Doppelklick starten
- `[GeoQuest.html downloaden (2.4 MB)]`
